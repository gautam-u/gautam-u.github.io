Know what changed. Know what to do next.

A dependency inventory does not need AI. Use an assistant when you want help understanding or fixing the evidence.

One security overview

Review secrets and dependency advisory matches with labeled severity colors. Open the filtered findings behind each number; coverage warnings stay separate from vulnerability counts.

Advisories on your schedule

Choose supported local project folders. Explicitly opt in to OSV checks and hourly or two-hour monitoring while Sieve is running and your Mac is awake. Last-check and next-check times make freshness visible.

Evidence for your assistant

Separately enable read-only project MCP to share saved package versions, advisory matches, and coverage. This does not grant source access, run fixes, or expose vault values.

New and changed findings are compared with a complete prior check. Missing evidence is unknown, not proof of safety. A disappeared match is not a verified fix, and local dependencies are not proof of what is deployed.

How it works

Scan. Identify. Secure.

Choose which local folders Sieve can read. Advisory monitoring and assistant sharing each require separate consent.

1

Grant Access Once

Select the folders you want Sieve to read. macOS bookmarks remember approved access; moved folders or revoked permissions may require reconnecting.

2

Scan Runs Automatically

Sieve scans chat databases and .env files, matching 100+ secret patterns derived from Gitleaks rulesets — all on-device, no cloud.

3

Review Findings

Findings are shown with redacted previews — never the raw value. Each finding links to the source file, rule, and rotation status.

4

Store in Vault

Rotate your leaked key and store the new value in Sieve Vault — backed by macOS Keychain. Copying requires Touch ID.

Features

More than a scanner

Review exposure, track remediation, and keep sensitive vault access behind macOS authentication.

🔒

Touch ID Vault

Store rotated secrets in macOS Keychain. Copy them with Touch ID or device password. Raw values are never displayed — copy only.

🧹

SQLite Redaction

Redact secrets directly from VS Code chat database files in place. Sieve automatically backs up the database before making any changes.

🤖

Permissioned MCP Integration

Connect compatible assistants to saved evidence through local stdio MCP. Project sharing is separately opt-in; legacy secret and vault-execution tools have separate controls and are not enabled by project sharing.

📊

Rotation Tracking

Mark secrets as rotated, revoked, or rotation-due. Track which findings have been handled and which still need attention.

🔎

100+ Detection Rules

Detects Stripe keys, GitHub PATs, AWS credentials, OpenAI keys, Anthropic keys, database URLs, JWT secrets, and dozens more.
